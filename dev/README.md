# Development Files

This folder contains development and testing scripts for the iSCORE-PDecipher package.

## Test Scripts

- **`test_app_functions.R`** - Core app functionality tests
- **`test_de_results.R`** - Differential expression module tests
- **`test_heatmap_generation.R`** - Heatmap module tests  
- **`test_launch.R`** - App launch diagnostics
- **`test_reactive_flow.R`** - Reactive data flow tests
- **`test_reliability.R`** - Stability and performance tests

## Utilities

- **`convert_guide_to_pdf.R`** - Utility to convert guides to PDF format

## Usage

These scripts are primarily for developers and maintainers. Run tests during development to ensure functionality remains stable.
